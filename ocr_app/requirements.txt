# 版本下限的取法：凡**把不可信文件交给原生解析器**的依赖，下限抬到"已知漏洞已修复"

# 下限那一版——把下限写成 10.0 就等于承诺"允许装到有 RCE 的版本"。

                       # 尚未发布（2026-11-06 实测 pip 最新仍为 6.12.0），发布后抬下限。
pypdfium2>=5.14.0,<6   # PDF 整页渲染（Apache-2.0，MIT 兼容）。
                       # 注意：5.14.0 内置 PDFium chromium/8076 仍带 CVE-2026-110155
                       # （AGG 光栅化堆溢出），**上游暂无修复版本**，见 pypdfium2#487；
                       # 这里只做"不降级"，缓解靠 input_prep 的子进程隔离 + README 风险声明。

                       # 96640 / 112401；12.3.0 修 CVE-2026-59204
requests>=2.34.2       # 2.34.2 为当前修复线；全部调用点均带 timeout

python-docx>=1.2.0
