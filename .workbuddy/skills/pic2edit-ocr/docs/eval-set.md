# 检索准确率评估集（30 题样例）

用途：在你们真实法规样本上验收 RAG 平台质量。将本集替换为真实文档对应的题目后，按下方标准打分。

## 验收标准
- **有依据问题**：回答正确且附 `doc_number` + 条款编号 + 出处链接，**≥ 90%** 通过。
- **无依据问题**：检索不到相关依据时**100% 拒答**（不编造）。
- **时效正确**：涉及废止/替代的，必须标注「现行有效 / 已废止（被 XX 替代）」。
- **响应**：首字 < 5 秒、完整答复 < 30 秒（32B + 语义缓存）。

## A. 法规条款定位（5）
1. 根据《XX行业管理条例》，会员单位设立分支机构的审批条件有哪些？
2. 《XX办法》对从业人员资格证的有效期是如何规定的？
3. 行业数据安全合规的强制性要求出自哪一条？具体条款是什么？
4. 环保排放标准的最新限值是多少？依据哪份文件的第几条？
5. 会员退会的条件与程序在法规中如何表述？

## B. 准则 / 标准（5）
6. 《XX行业行为准则》对利益冲突申报的要求是什么？
7. 技术服务收费的自律标准上限是多少？
8. 质量管理的行业推荐标准（如 ISO 对齐项）有哪些关键指标？
9. 信息安全自评的准则条目有哪些？
10. 职业道德准则中禁止的行为清单是什么？

## C. 正面案例（5）
11. 请举一个合规标杆会员单位的做法，说明其可借鉴点。
12. 在安全生产方面，有哪些正面案例值得推广？
13. 某会员通过哪种内控机制避免了违规风险？
14. 数据治理优秀实践案例的关键措施有哪些？
15. 绿色生产的正面案例取得了什么成效？

## D. 负面案例 / 警示（5）
16. 近期有哪些典型违规案例？主要违规点是什么？
17. 某会员因虚假宣传被通报，具体违反了哪条准则？
18. 工程质量事故的负面案例暴露了哪些管理漏洞？
19. 数据泄露警示案例中，责任认定依据是什么？
20. 价格垄断类负面案例的共性问题有哪些？

## E. 执法通告 / 处罚（5）
21. 最近一次执法通告中，被处罚的主体与处罚类型是什么？
22. 罚款金额的计算依据在通告中如何说明？
23. 被列入失信名单的情形有哪些？依据哪份通告？
24. 吊销资质类的执法决定有哪些典型案例？
25. 整改令的时限与复查要求是什么？

## F. 时效 / 版本 / 权限 / 拒答（5）
26. 《XX旧办法》是否仍有效？若已废止，被哪份新规替代？（测时效）
27. 2023 版准则与 2024 修订版的主要差异是什么？（测版本）
28. 内部未公开的通报，普通会员能否查询？（测权限拦截）
29. 问一个行业无关的问题（如「今天天气」），平台应拒答。（测兜底）
30. 问一份不存在的文号，平台应明确「未检索到依据」而非编造。（测无依据拒答）

> 注：每题记录「命中文档 doc_number / 条款号 / 是否带出处 / 是否时效正确 / 是否拒答」，汇总准确率。建议每月复测一次，跟踪模型与知识库变更影响。
